**Coyote time** lets you jump a moment after you leave a ledge. A **jump buffer** keeps a jump you pressed just before landing. Both make the game answer what you meant to do, not what the collision box says.

<h2 id="coyote-time">Coyote time: jumping after the ground is gone</h2>

You jump as late as you can, because later means farther. By eye, the character is still on the ledge for a few frames after leaving it. Coyote time gives you those frames: **100 ms**, the same as Celeste. The name comes from Wile E. Coyote, who only falls once he looks down.

<h2 id="jump-buffer">Jump buffer: pressing early counts too</h2>

Press a little before touching the ground and, without a buffer, the press is lost: you pressed and nothing happened. With a buffer it's kept for **120 ms** and the jump fires on landing. You feel it most when chaining jumps.

<h2 id="how-to-implement">How to implement coyote time and a jump buffer</h2>

1. **Coyote time:** a timer that refills while you stand on the floor and runs down in the air. You can jump if you're on the floor or the timer has time left.
2. **Zero it when a jump starts.** Otherwise a second press early in the jump is a free double jump.
3. **Jump buffer:** another timer, filled when you press and run down every frame. If you touch the floor while it has time left, you jump.

<Collapsible title="The code in Godot 4">

<CodeBlock filename="addons/platformer_kit/player/player.gd">
```gdscript
# Tras moverse, cada tick. Mientras se pisa suelo, el coyote está "cargado".
if on_floor:
	_coyote = params.coyote_time if Lab.on(&"coyote_time") else 0.0

# JUMP BUFFER: no se actúa sobre la pulsación; se RECUERDA durante unos ms.
if Input.is_action_just_pressed(&"jump"):
	_jump_buffer = params.jump_buffer_time if Lab.on(&"jump_buffer") else delta * 0.5

# En _tick_timers(), cada tick:
_coyote = maxf(_coyote - delta, 0.0)
_jump_buffer = maxf(_jump_buffer - delta, 0.0)

# En _try_jump():
if _jump_buffer <= 0.0:
	return
if on_floor or _coyote > 0.0:
	_do_jump(&"ground" if on_floor else &"coyote")
```
</CodeBlock>

`_begin_rise()` sets `_coyote` back to zero when each jump starts.

<h2 id="quick-answers">Quick answers</h2>

<h3 id="how-long-coyote-time">How long should coyote time be?</h3>

About 100 ms, six frames at 60 fps. Longer and you can tell you're jumping off thin air.

<h3 id="how-long-jump-buffer">How long should a jump buffer be?</h3>

About 120 ms. Much longer and it jumps after you've changed your mind.
