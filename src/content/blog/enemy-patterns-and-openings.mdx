An **enemy attack pattern** is the fixed loop an enemy runs every time it attacks: warn, attack, recover. Because it's fixed you can learn it, and the recovery is your **opening**: the hopper below sits open for **0.7 s** after every leap.

<h2 id="what-is-an-enemy-pattern">Enemy attack patterns: every enemy asks one question</h2>

Every enemy asks the two questions Mike Stout names ([Game Developer, 2015](https://www.gamedeveloper.com/design/enemy-attacks-and-telegraphing)): "Can you avoid my damage?" during [the warning](/blog/telegraphing-attacks/), and "Can you hit me?" during the recovery. Variety comes from the first question, not from more health: the walker asks if you know your reach, the charger if you're in its line, the hopper if you'll move after it commits, the drone if you're still moving.

<h2 id="openings-guard">Openings: the guard you can't mash</h2>

Hit the guard's shield from the front and you get a clang, no damage and a recoil 1.9 times stronger than usual. It asks whether you can wait, and it opens four ways: for 0.85 s after its thrust, from above, from behind, and during the 0.45 s it takes to turn after you dash through it. Against a walker you press attack; against a guard you decide *when*.

<h2 id="how-to-implement">How to implement enemy attack patterns</h2>

1. Put the shared loop in one base class: patrol, warning, attack, recovery. Each enemy only decides what to do in each state.
2. End every attack in an open state of fixed length, like a recovery, a daze or a landing. An enemy with no opening isn't fair.
3. If an attack aims, lock the aim halfway through the warning. A shot that corrects until the last frame can't be dodged by skill.
4. Make a shield a check on each hit, not a second collision box: it blocks only slashes from the front while the guard is up.

```gdscript
## ¿Para el escudo este golpe? Sólo los tajos que vienen de frente y con la guardia alta.
func _blocks(hit: Hit) -> bool:
	if hit.kind != &"slash" or state == &"recover":
		return false
	if hit.direction.y > 0.5:
		return false   # desde arriba: el escudo no cubre la cabeza
	if not is_instance_valid(hit.source) or not hit.source is Node2D:
		return false
	var attacker_side := signf((hit.source as Node2D).global_position.x - global_position.x)
	return attacker_side == float(facing)
```

<h2 id="quick-answers">Quick answers</h2>

<h3 id="what-is-an-opening">What is an opening in combat design?</h3>

A window where the enemy can't defend or answer and you can hit it freely: the recovery after an attack, a daze, a landing. The drone's is plainer, the 1.5 s between shots.

<h3 id="how-many-enemy-types">How many enemy types does a game need?</h3>

Fewer than it seems, if each asks a different question. Five plus a boss is enough here, and pairs like a walker under a drone add situations without new code.
