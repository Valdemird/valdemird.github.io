El **coyote time** te deja saltar un instante después de salir de una cornisa. El **jump buffer** guarda un salto que pulsaste justo antes de aterrizar. Los dos hacen que el juego responda a lo que quisiste hacer, no a lo que dice la caja de colisión.

<h2 id="coyote-time">Coyote time: saltar cuando ya no hay suelo</h2>

Saltas lo más tarde que puedes, porque más tarde es más lejos. A ojo, el personaje sigue sobre la cornisa unos fotogramas después de dejarla. El coyote time te da esos fotogramas: **100 ms**, lo mismo que usa Celeste. El nombre viene del Coyote de los dibujos, que sólo cae cuando mira abajo.

<h2 id="jump-buffer">Jump buffer: pulsar pronto también cuenta</h2>

Si pulsas un poco antes de tocar el suelo, sin buffer la pulsación se pierde: pulsaste y no pasó nada. Con buffer se guarda **120 ms** y el salto sale al aterrizar. Se nota sobre todo al encadenar saltos.

<h2 id="how-to-implement">Cómo implementar coyote time y jump buffer</h2>

1. **Coyote time:** un temporizador que se recarga mientras pisas suelo y baja en el aire. Puedes saltar si estás en el suelo o si le queda tiempo.
2. **Ponlo a cero al saltar.** Si no, una segunda pulsación al empezar el salto es un doble salto gratis.
3. **Jump buffer:** otro temporizador que se carga al pulsar y baja cada fotograma. Si tocas suelo y le queda tiempo, saltas.

<Collapsible title="El código en Godot 4">

<CodeBlock filename="addons/platformer_kit/player/player.gd">
```gdscript
# Tras moverse, cada tick. Mientras se pisa suelo, el coyote está "cargado".
if on_floor:
	_coyote = params.coyote_time if Lab.on(&"coyote_time") else 0.0

# JUMP BUFFER: no se actúa sobre la pulsación; se RECUERDA durante unos ms.
if Input.is_action_just_pressed(&"jump"):
	_jump_buffer = params.jump_buffer_time if Lab.on(&"jump_buffer") else delta * 0.5

# En _tick_timers(), cada tick:
_coyote = maxf(_coyote - delta, 0.0)
_jump_buffer = maxf(_jump_buffer - delta, 0.0)

# En _try_jump():
if _jump_buffer <= 0.0:
	return
if on_floor or _coyote > 0.0:
	_do_jump(&"ground" if on_floor else &"coyote")
```
</CodeBlock>

`_begin_rise()` pone `_coyote` a cero al empezar cada salto.

<h2 id="quick-answers">Respuestas rápidas</h2>

<h3 id="how-long-coyote-time">¿Cuánto debe durar el coyote time?</h3>

Unos 100 ms, seis fotogramas a 60 fps. Más y se nota que saltas desde el aire.

<h3 id="how-long-jump-buffer">¿Cuánto debe durar el jump buffer?</h3>

Unos 120 ms. Mucho más y salta cuando ya cambiaste de idea.
